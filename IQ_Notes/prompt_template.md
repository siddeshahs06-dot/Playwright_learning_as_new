# Prompt Template for Saving IQ Notes

Use this prompt whenever you want me to explain a concept and save it as a `.md` file in the `IQ_Notes` folder.

---

## Template

```
Explain [CONCEPT_NAME] with an example from [YOUR_FILE_PATH].

Format it as a table first, then add a plain explanation below.

Save it as IQ_Notes\[CONCEPT_NAME]_IQ.md
```

## Example (filled in)

```
Explain Source Code vs Byte Code vs Binary Code with an example from Chapter_01_JS_BASICS\intro.js.

Format it as a table first, then add a plain explanation below.

Save it as IQ_Notes\soucecode_bytecode_bunaeycode_IQ.md
```

## What you'll get back

| Feature | What happens |
|---------|-------------|
| **Format** | A comparison table + plain explanation |
| **Example** | Tied to a file from your project |
| **File saved** | `IQ_Notes\[concept]_IQ.md` — ready to review later |

## Variations

| If you want... | Say... |
|---|---|
| Just a definition | "Define [concept] in simple terms and save to IQ_Notes" |
| A diagram/flow | "Explain [concept] with a text-based flow diagram and save to IQ_Notes" |
| Compare multiple things | "Compare [A], [B], and [C] using a table and save to IQ_Notes" |
| Step-by-step breakdown | "Explain [concept] step by step with an example and save to IQ_Notes" |
